Workbench Tutorial

A made-up reaction-yield dataset for learning the tools. Every effect in it was put there on purpose.

About the data

Each row is one run of a made-up chemical process. There are 576 runs, carried out over 24 weeks. None of this is real data. It was generated so that every tool in this workbench has something definite to find, which makes it safe to be wrong while you are still learning the controls.

ColumnMeaning
run_id, weekWhich run, and the week it was carried out in (1 to 24)

temperature_cReaction temperature, °C. Six settings: 40, 50, 60, 70, 80, 90
pressure_atmReaction pressure, atmospheres. Anywhere from 1 to 5
stir_rate_rpmStirrer speed, rpm. Anywhere from 200 to 800
lab_humidity_pctRelative humidity in the lab that day, %
yield_pctThe main response. Percent of the theoretical maximum recovered
purity_pctA second response. Purity of the product, %. Blank for week 7, when the instrument was down

What to do

Open the Guided tour and work through it. Each step is a question you answer with the tool, and each has the answer folded up underneath so you can check yourself. Nothing is locked and nothing is graded — break it, undo it, try the other button.

When you are done you will have used every control in here at least once, and you will have met four traps that also appear in real data.

The four tabs

Table lists the runs. Click a column heading to sort by it.

Plot is the main instrument. Pick a response, pick something to plot it against, pick how to draw it. The Filters panel above it decides which runs everything is computed from, so narrowing it changes every chart and every statistic on every tab.

Statistics gives means, medians and spreads in a table, grouped however you like.

Calculator makes new columns out of old ones, for all 576 runs at once. Your columns then appear everywhere else.

Reading a slope

A fitted slope comes with a ± figure, its standard error. As a rough rule, a slope smaller than twice its own standard error is not distinguishable from no relationship at all. R² is a different question: it is the share of the variation the line accounts for. A slope can be certain and still explain almost nothing.

    What you can use in a formula
    • Any column name, such as yield_pct or temperature_c
    • Arithmetic: + - * / ( ) and powers with **
    • Comparisons give 1 (true) or 0 (false): catalyst == "B", temperature_c > 70
    • Choices: condition ? a : b, for example temperature_c < 65 ? "cool" : "hot"
    • Functions: log(x) (natural), log10(x), sqrt(x), abs(x), round(x)
    • mean("yield_pct"): the mean of a column over all rows
    • meanBy("yield_pct", "catalyst"): for each row, the mean of yield_pct over all rows that share its catalyst. You can list more than one column: meanBy("yield_pct", "catalyst", "temperature_c")
