# Data Workbench Tutorial

A practice dataset and guided tour for learning the analysis workbench used in
[Full Moon Births](https://github.com/Lufox2021/Full-Moon-Births),
[Factors Affecting Behavior and ADHD Diagnosis](https://github.com/Lufox2021/Factors-Affecting-Behavior-and-ADHD-Diagnosis),
[Climate Trends](https://github.com/Lufox2021/Climate-Trends) and
[Climate Change Investigation](https://github.com/Lufox2021/Climate-Change-Investigation).

**Live tool:** open `index.html`. The data is embedded; no server needed.

## The data is made up

576 runs of an invented chemical process over 24 weeks. None of these numbers are real.
They were generated by `gen.py` so that every control in the workbench has something definite
to find, which makes it safe to be wrong while learning the interface.

| Column | Meaning |
| --- | --- |
| `run_id`, `week` | Which run, and the week it was carried out in (1–24) |
| `catalyst` | A, B or C — 192 runs each |
| `shift` | Day or Night — 288 runs each |
| `temperature_c` | 40, 50, 60, 70, 80, 90 |
| `pressure_atm` | 1 to 5 |
| `stir_rate_rpm` | 200 to 800 |
| `lab_humidity_pct` | Relative humidity that day |
| `yield_pct` | The main response |
| `purity_pct` | A second response. Blank for week 7 |

## What was built in, and what a student should find

| Built in | Found with the tool |
| --- | --- |
| Strong linear effect of temperature | yield ~ temperature: +0.255 ± 0.011, 23 SE, R² = 0.48 |
| No effect of stirrer speed | 0.6 SE, R² = 0.001 — what nothing looks like |
| Quadratic effect of pressure, optimum at 3 atm | straight-line fit R² = **0.000**; the binned averages trace 39% → 45% → 40% |
| No effect of shift | Day 42.55, Night 42.48 |
| Catalyst × temperature interaction | main effects nearly flat (42.5 / 43.1 / 42.0), but the lines cross in the 60s: A best at 40 °C, B ahead by 9 points at 90 °C |
| Process drift over 24 weeks | humidity also drifts (R² = 0.76 vs week), so yield ~ humidity gives +0.46 ± 0.06 at 7.4 SE and causes nothing |
| Temperature lowers purity | −0.081 ± 0.002, R² = 0.72 — the two responses disagree |
| Instrument down in week 7 | purity fits run on n = 552, not 576 |

## The guided tour

Twelve steps on the **Guided tour** tab, each a question answered with the tool, each with the
answer folded up underneath. They cover sorting, filtering, fitting, reading a standard error,
the hidden curve, main effects, interactions, splitting by group, the clock trap, two responses
in conflict, and building a derived column.

Regenerate the data with `python3 gen.py` — the seed is fixed, so it reproduces exactly.
